# How to Use Advanced Input Fields

**Summary:** Learn about the different types of input fields you will encounter across the apps and how to interact with them.

## Overview
Throughout AIBook, AIStudio, and AICodex, standard text boxes will automatically adapt themselves based on the kind of data they require. This means a single input field might act like a text box, a dropdown menu, or a date picker depending on context. 

Here are the advanced input fields you will see:

## 1. Number and Text Fields
The most common input fields. They work exactly like standard text boxes. 
- **Text:** You can type any text. It will feature a clear button (`×`) on the right when there is text inside.
- **Number:** Will restrict your keyboard and input strictly to numeric characters.

## 2. Dropdowns (Combo & Select Fields)
When an input field requires you to choose from a list of options, it acts as a dropdown.
- **Select Mode:** The field is read-only. Clicking anywhere inside it or on the down arrow (`▼`) will open a list of options to choose from.
- **Combo Mode:** The field is editable. You can freely type to quickly filter the list of options, similar to a search bar.
- *Tip:* Clicking the refresh icon (`↻`) on the left of these fields will reload the latest choices from the server.

## 3. Date and Time Fields
When a field expects a date, it will be read-only text.
- Click the calendar icon (`📅`) on the right side of the field to open a visual Date or Time picker. Once you select a value, the text box will update.

## 4. Checkboxes (Boolean Fields)
Fields that represent a simple "Yes/No" or "True/False" choice.
- They display as read-only text (e.g., "Yes" or "No").
- Click the checkbox outline icon on the right side (or tap the text itself) to toggle between the states.

## 5. Tag Lists
Some fields accept a list of multiple items instead of just one (like assigning multiple roles or categories). 
- **View Mode (👁):** They appear as small graphical "chips" side-by-side. 
  - To delete a tag, tap the trash can icon (`🗑`), then click the `×` on the tags you want to remove. Tap the checkmark (`✓`) when done.
- **Add Mode (＋):** Tap the `👁` icon to switch to Add Mode (it becomes a `＋`). The textbox becomes editable. Type your new tag and press Enter or the `＋` on the right side to add it to the list.

## 6. Table Filters
When navigating large tables of data, the search bar above the table will have a special Filter Operator badge on the left side.
- Tap the **badge on the left side** to cycle through how it searches:
  - **C (Contains):** Shows rows that contain your search anywhere.
  - **S (Starts With):** Shows rows that begin with your search.
  - **E (Ends With):** Shows rows that end with your search.
  - **X (Except):** Hides rows that contain your search.
- After typing your search term, click the checkmark (`✓`) on the right to apply it.
