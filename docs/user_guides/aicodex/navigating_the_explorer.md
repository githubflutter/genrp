# Navigating the Explorer in Admin Home

**Summary:** Learn how to use the new side panel UExplorer to browse and organize your app components and database schemas.

## Overview
The **Explorer** is the main navigational side panel located on the left side of your screen when inside the **Admin Home** view of AIStudio and AICodex. It acts exactly like a file browser on your computer.

All of your data models (schemas), user interface components, and configurations are organized in this tree structure.

## Interacting with the Explorer
1. **Expanding Folders**: Click the small arrow next to any folder to see the items inside.
2. **Selecting Items**: Click directly on a schema or component name in the Explorer to open its details in the main right-hand panel. This allows you to edit columns, metadata, and form fields.
3. **Drafts**: Some rows might be marked as *drafts* (temporarily saved changes). Once you are ready, you can publish them.

## The Explorer Filter Bar
At the top of the side panel, there is a dedicated search bar (Filter Field). This is powerful for large projects:

* Simply start typing the name of the model or schema you are looking for.
* **Filter Options**: Tap the Operator Badge (like **C**, **S**) on the left side of the search bar to refine how it searches. For instance, **C** is "Contains" and **S** is "Starts With".
* Tap the checkmark on the right (`✓`) to apply the search. Only nodes matching your search will appear in the Explorer. Click the clear button (`×`) to reset.
